## 🧠 About

This project is a **Snake game written in Java**, using Java UI libraries and robust structure to simulate classic Snake gameplay. Players control the snake to eat apples, grow in size, and avoid collisions with walls or itself.

You can run and explore the game to understand game loops, collision detection, key event handling, and simple graphics in Java.

---

## 🚀 Features

- 🟩 Classic Snake gameplay
- 🎮 Keyboard controls (Arrow keys)
- 🔁 Continuous game loop
- 📈 Growing snake mechanics
- 🎯 Score tracking

---

## 🧩 How to Play

1. Use the **arrow keys** to navigate the snake.
2. Eat food to grow longer.
3. Avoid hitting the walls or your own tail.
4. See how long you can survive and grow your score!
